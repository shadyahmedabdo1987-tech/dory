# خطة التطوير · Roadmap

## v2.0 — أدمن وأعضاء على السيرفر ✅
- Firebase: حسابات لأصحاب الجمعيات، ودخول الأعضاء بالكود ورقم الموبايل
- أقساط شهرية، أو كل ٣ شهور، أو أسبوعية
- تأجيل فترة، ودور إضافي، وقسط إضافي، وتحريك الفترات، وقرعة
- العضو يبلّغ إنه دفع، والأدمن يأكد
- حساب العضو بشكل تطبيق البنك
- قواعد حماية على السيرفر واختبارات ليها

## v2.1 — قبل الإطلاق العام
- [ ] إشعارات Push: تذكير قبل القسط، وتنبيه للأدمن لما عضو يبلّغ بالدفع (Cloud Functions + FCM)
- [ ] رفع صورة إيصال التحويل مع "دفعت" (Firebase Storage)
- [ ] App Check وتنبيهات الميزانية
- [ ] Crash reporting (Sentry)
- [ ] استيراد الأعضاء من جهات الاتصال

## نموذج الربح
| الباقة | المميزات |
|---|---|
| مجاني | جمعيتين، وكل المميزات الأساسية، وأعضاء بلا حدود |
| Pro (اشتراك شهري أو سنوي) | جمعيات بلا حدود، وإشعارات، وإيصالات، وتقارير PDF، وأكتر من أدمن |

> **العضو دايمًا مجاني**، لأن كل عضو بيدخل هو عميل محتمل يفتح جمعية بنفسه بعدين.
