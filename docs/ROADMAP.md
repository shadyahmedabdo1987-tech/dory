# خطة التطوير · Roadmap

## v1.0 — الأساس ✅
- إنشاء وتعديل ومسح الجمعيات (شهري / أسبوعي)
- القرعة وترتيب الأدوار يدويًا
- تسجيل الدفع لكل عضو في كل دور، وتسليم القبض
- المتأخرات وكشف حساب لكل عضو
- تذكير واتساب فردي وملخص للجروب
- تخزين محلي كامل، واجهة عربية RTL

## v1.1 — سهولة الاستخدام
- [ ] استيراد الأعضاء من جهات الاتصال (`expo-contacts`)
- [ ] إشعارات محلية قبل ميعاد القسط بيوم (`expo-notifications`)
- [ ] نصف سهم / أكتر من سهم للعضو الواحد
- [ ] تصدير كشف الجمعية PDF ومشاركته
- [ ] الوضع الليلي

## v1.2 — الأمان والنسخ الاحتياطي
- [ ] نسخة احتياطية واسترجاع (ملف / Google Drive / iCloud)
- [ ] قفل التطبيق بالبصمة (`expo-local-authentication`)

## v2.0 — الجمعية المشتركة (أساس النمو)
- [ ] حسابات وتسجيل دخول برقم الموبايل
- [ ] رابط دعوة: كل عضو يشوف دوره ومدفوعاته من موبايله
- [ ] العضو يأكد إنه دفع، والمسؤول يوافق
- [ ] كل عضو بيعزم الباقيين ← انتشار طبيعي للتطبيق
