## الفكرة

الجمعية نظام ادخار بيستخدمه ملايين الناس في مصر والوطن العربي، وأغلبهم لسه بيديروه بالكشكول ورسايل الواتساب. **دوري** بيخلّي:

- **صاحب الجمعية (الأدمن)** يتحكم في كل حاجة: الأعضاء، والجدول، والتحصيل، والتأكيد.
- **كل عضو** يدخل من موبايله ويشوف حسابه **زي تطبيق البنك**: دوره في القبض، والأقساط اللي عليه، واللي دفعه، والمتأخر.

## المميزات

### لصاحب الجمعية
| | |
|---|---|
| 📅 **مواعيد مرنة** | أقساط **شهرية** أو **كل ٣ شهور** أو **أسبوعية** |
| ⏸️ **تأجيل** | تأجيل شهر (أو فترة) لكل الأدوار اللي بعده بضغطة — للعيد أو الظروف |
| ➕ **دور إضافي** | زيادة دور قبض في آخر الجدول (سهم تاني، عضو جديد، أو عمولة) |
| 💵 **قسط إضافي** | الكل يدفع مبلغ زيادة في فترة من غير ما حد يقبض، مع ذكر السبب |
| 🎡 **عجلة القرعة** | عجلة بأسماء الأعضاء بتلف وتطلّع الأدوار واحد واحد، مع تحريك أي فترة لفوق أو لتحت |
| ✅ **تأكيد الدفع** | العضو يختار طريقة الدفع (كاش / إنستاباي / فودافون كاش) ويرفق صورة التحويل، وصاحب الجمعية يشوفها ويأكد أو يرفض |
| 💸 **طلبات القبض** | صاحب الدور يطلب يقبض إزاي، وصاحب الجمعية يوافق أو يرفض أو يعدّل، وبعدين يحوّل ويرفق إيصال التحويل |
| 💰 **تسليم القبض** | تسجيل إن صاحب الدور استلم، ومتابعة نسبة إنجاز الجمعية |
| 💬 **واتساب** | دعوات فيها الكود، وتذكير للمتأخرين، وملخص للجروب |
| 🔔 **إشعارات** | إشعار لحظي لما عضو يبلّغ إنه دفع، وتذكير بميعاد التحصيل وبالمتابعة |

|---|---|

## الأمان وقاعدة البيانات

التطبيق مبني علشان يشتغل لآلاف المستخدمين من غير مشاكل:

- **سيرفر مركزي واحد (Firebase)**: كل اللي يحمّل التطبيق يتوصل على طول، من غير أي إعدادات.
- **عمليات ذرّية**: إنشاء جمعية، أو انضمام عضو، أو تعديل الأعضاء، كلها بتتم مرة واحدة كاملة (batch أو transaction). لو النت قطع، ما فيش حاجة بتتحفظ نصها.
- **منع التعارض**: تعديلات الجدول بتتم جوه transaction، فلو الأدمن عدّل من جهازين في نفس الوقت، محدش بيمسح تعديل التاني.
- **قواعد حماية على السيرفر** ([`firestore.rules`](firestore.rules)):
  - محدش يشوف الجمعية غير صاحبها وأعضاؤها.
  - العضو ما يقدرش يبلّغ بالدفع غير عن نفسه، وما يقدرش يأكد ولا يعدّل حاجة.
  - **أرقام الموبايلات بيشوفها صاحب الجمعية بس**، والأعضاء ما بيشوفوهاش.
  - البيانات بتتراجع على السيرفر نفسه: الأنواع، والمبالغ، والتواريخ، والأحجام، والحقول المسموحة.
- **اختبارات لقواعد الحماية** ([`tests-rules/`](tests-rules)) بتشتغل على Firebase Emulator مع كل تعديل على GitHub.
- **App Check**: السيرفر بيقبل الطلبات من تطبيق "دوري" الأصلي بس، عن طريق Play Integrity على أندرويد و App Attest على آيفون.
- **رسايل خطأ واضحة بالعربي**، ومحاولة تانية تلقائية لو النت ضعيف.

## التقنيات

- **Expo SDK 54** + **React Native 0.81**: كود واحد لأندرويد وآيفون
- **Firebase**: Auth (إيميل لصاحب الجمعية، ودخول بالكود والرقم للعضو) + Cloud Firestore + Cloud Functions + App Check
- **expo-notifications**: تذكير محلي على الموبايل، وإشعارات لحظية عن طريق Expo Push
- **Expo Router** و **TypeScript strict**
- منطق الجمعية في [`src/core`](src/core) مكتوب TypeScript نقي من غير أي اعتماد خارجي، ومغطّى باختبارات

```
app/                       الشاشات (Expo Router)
  index.tsx                الترحيب / الرئيسية
  auth.tsx                 حساب صاحب الجمعية
  join.tsx                 انضمام عضو (كود + رقم)
  new.tsx                  جمعية جديدة
  circle/[id].tsx          لوحة الأدمن أو حساب العضو
  circle/settings/[id].tsx الإعدادات والأعضاء
src/
  core/                    منطق الجمعية: الجدول، والمدفوعات، والحسابات
  data/                    Firebase: الدخول، والبيانات، والاشتراكات اللحظية
  features/                AdminView و MemberView و CircleForm
  notifications/           التذكير المحلي والإشعارات اللحظية
  ui/                      نظام التصميم
functions/                 Cloud Functions (إشعارات الدفع والتأكيد والقبض)
tests/                     اختبارات المنطق
tests-rules/               اختبارات قواعد الحماية
firestore.rules            قواعد الحماية
```

## التشغيل

1. جهّز Firebase زي ما هو مشروح في **[docs/FIREBASE_SETUP.md](docs/FIREBASE_SETUP.md)**، دي خطوة بتتعمل مرة واحدة.
2. بعدها:

```bash
npm install
npx expo install --fix
cp .env.example .env      # وحط مفاتيح Firebase
npm start                 # امسح الـ QR بتطبيق Expo Go
```

| الأمر | الوظيفة |
|---|---|
| `npm test` | اختبارات منطق الجمعية |
| `npm run test:rules` | اختبارات قواعد الحماية (Firebase Emulator) |
| `npm run typecheck` | فحص TypeScript |
| `npm run deploy:rules` | رفع قواعد الحماية على Firebase |

## النشر على المتاجر

```bash
npm install -g eas-cli
eas login
eas env:create   # ضيف متغيرات EXPO_PUBLIC_FIREBASE_* لبيئة production
eas build --platform android --profile production
eas build --platform ios --profile production
```
